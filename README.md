# Praecursor-EGX

Praecursor-EGX is an evidence-driven research platform designed to identify Egyptian Exchange (EGX) stocks in the earliest stages of potentially significant price moves.

Unlike traditional stock screeners, Praecursor does not rank today's top gainers. Instead, it searches for combinations of:

- Material corporate catalysts
- Early accumulation
- Abnormal volume
- Liquidity shifts
- Ownership changes
- Financial improvements
- Historical patterns

Every signal is measured, scored, and archived so the system continuously improves over time.

Price follows money.

News explains money.

Evidence beats opinion.
